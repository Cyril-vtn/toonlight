# Code of conduct

Toonlight follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, welcome newcomers, accept constructive criticism, and focus on
what is best for the community. Harassment, insults, discriminatory language, personal attacks and
publishing other people's private information are not accepted, in issues, pull requests,
discussions or any other project space.

## Reporting

If someone behaves unacceptably, report it privately to the maintainers through GitHub's
"Report content" button on the comment or issue, or by opening a
[private security advisory](https://github.com/Cyril-vtn/toonlight/security/advisories/new) marked
"Code of conduct". Reports are kept confidential. Maintainers may edit or remove contributions and
warn or ban people who break these rules, as described in the Contributor Covenant's enforcement
guidelines.
