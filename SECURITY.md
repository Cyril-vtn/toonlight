# Security policy

## Supported versions

Security fixes go into the latest release. Please update before reporting.

## Reporting a vulnerability

Please **don't** open a public issue for a security problem (for example a project or picture
file that crashes the app or runs code, or a problem in the AI (MCP) server).

Report it privately instead:
[open a security advisory](https://github.com/Cyril-vtn/toonlight/security/advisories/new) with
what you found, how to reproduce it and which version and system you use. You will get an answer
as soon as possible; once a fix is released, the advisory is published with credit to you, unless
you prefer to stay anonymous.
